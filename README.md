# EASTSAT 자재 관리 시스템 (EASTSAT Management System)

이 프로젝트는 엑셀 파일을 데이터베이스로 사용하는 로컬 자재 관리 및 이미지 검색 시스템입니다.

## 주요 기능
- **엑셀 기반 데이터 관리**: `pasco.xlsx` 파일을 직접 읽고 쓰며 실시간으로 데이터를 관리합니다.
- **이미지 검색 및 표시**: 자재 코드별 이미지를 검색하고 격자 형태로 시각화합니다.
- **사용자 권한 관리**: `사용자.xlsx`를 통한 로그인 및 권한(조회/관리) 제어 기능.
- **실시간 수정**: 품명, 가격, 자재코드 등을 웹 인터페이스에서 직접 수정하고 엑셀에 저장합니다.

## 설치 및 실행 방법

### 1. 필수 소프트웨어
- [Node.js](https://nodejs.org/) (버전 14 이상 권장)

### 2. 의존성 설치
프로젝트 폴더에서 다음 명령어를 실행하여 필요한 패키지를 설치합니다.
```bash
npm install
```

### 3. 데이터 파일 준비
프로젝트 루트 폴더에 다음 파일들이 있어야 합니다.
- `pasco.xlsx`: 전체 자재 데이터 및 이미지가 포함된 메인 엑셀 파일.
- `사용자.xlsx`: 사용자 ID, 비밀번호, 권한 정보가 포함된 파일.

> **주의**: 이 파일들은 크기 또는 보안상의 이유로 기본적으로 `.gitignore`에 포함되어 있어 깃허브에 업로드되지 않을 수 있습니다. 로컬에서 직접 파일을 복사해 넣어주세요.

### 4. 서버 실행
서버를 실행하려면 다음 명령어를 입력합니다.
```bash
npm start
```
서버가 실행되면 브라우저에서 `http://localhost:3000`으로 접속할 수 있습니다.

## 기술 스택
- **Frontend**: HTML5, Vanilla CSS, JavaScript
- **Backend**: Node.js, Express
- **Library**: ExcelJS (엑셀 조작), Multer (이미지 업로드), CORS

## 폴더 구조
- `app.js`: 프론트엔드 로직
- `server.js`: 백엔드 API 서버
- `index.html`: 메인 레이아웃
- `style.css`: UI 디자인 스타일
- `tools/`: 데이터 검증 및 테스트용 보조 스크립트
- `uploads/`: 이미지 업로드용 임시 폴더
